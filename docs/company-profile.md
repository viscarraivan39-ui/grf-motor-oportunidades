# Perfil Empresarial

## Modelo conceptual

```text
company
├── identity
├── activities
├── capabilities
├── resources
├── experience
├── geography
├── financial_capacity
├── compliance
├── preferences
└── restrictions
```

## Principio

Una empresa puede tener una actividad declarada, una capacidad real y una capacidad demostrable. El sistema debe mantener estas dimensiones separadas.

## Empresas piloto

### Empresa forestal
Tala, poda, explotación de bosque, plantación, manejo forestal, construcción menor y servicios de terreno.

### Emotion Chile SpA
Aplicaciones, páginas web, automatizaciones, IA, desarrollo tecnológico y servicios complementarios/logística.

# GRF — Motor de Oportunidades Empresariales

Versión: 0.1.0  
Estado: Desarrollo inicial  
MVP: Etapas 1, 2 y 3

## Visión

Crear una plataforma inteligente capaz de comprender una empresa, identificar sus capacidades reales y encontrar oportunidades de negocio compatibles con ella, inicialmente dentro de Mercado Público.

La plataforma evolucionará desde un buscador de oportunidades hacia un ecosistema de inteligencia empresarial.

## MVP

1. Perfil empresarial.
2. Modelo y comprensión de Mercado Público.
3. Motor de compatibilidad y matching.

## Empresas piloto

- Empresa forestal piloto.
- Emotion Chile SpA.

## Principio

> No buscar oportunidades para una empresa. Entender primero la empresa y luego buscar las oportunidades que realmente tienen sentido para ella.

## Regla de escalabilidad

Las empresas deben ser datos, no código. El sistema debe permitir agregar nuevas empresas sin modificar la lógica central.
